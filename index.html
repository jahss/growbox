How the comparison works

Guaranteed % shows the analysis printed on the label, including all listed secondary nutrients and micros.

Elemental ppm converts P₂O₅ → P and K₂O → K, then calculates every listed nutrient at the selected standardized N, P or K level.

Why standardize? Labels differ in strength, so comparing percentages or equal doses mostly shows which bottle is more concentrated. A standardized comparison instead doses each line to the same target, such as 160 ppm N, and shows everything else that comes with it. Every line then gets the same amount of the element you picked, and the other values show how their P, K, Ca, Mg, S and micros really differ.

The dose is how much of each line it takes to reach that target. For each nutrient, green marks the highest value and orange the lowest. A line that contains none of the chosen element can't reach the target, so it shows as “Cannot standardize”.
